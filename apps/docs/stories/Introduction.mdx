# Commonspace UI

A standalone React design system for content-rich and social products.

## Import order

```tsx
import '@commonspace/tokens/styles.css';
import '@commonspace/icons/styles.css';
import '@commonspace/ui/styles.css';
import '@commonspace/social/styles.css';
```

Wrap the application in `CommonspaceProvider` to scope theme, density, and accent roles.

The visual packages do not own routing, authentication, API requests, TanStack Query, SWR, or Zustand state.
