# Unpopping Candy

A standalone React design system for content-rich and social products.

## Import order

```tsx
import '@unpopping-candy/tokens/styles.css';
import '@unpopping-candy/icons/styles.css';
import '@unpopping-candy/ui/styles.css';
import '@unpopping-candy/social/styles.css';
```

Wrap the application in `UnpoppingCandyProvider` to scope theme, density, and accent roles.

The visual packages do not own routing, authentication, API requests, TanStack Query, SWR, or Zustand state.
