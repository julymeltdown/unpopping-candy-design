# Review rubric

## Blocking

- Invalid or private package import.
- Invented component or prop.
- Missing accessible name, keyboard operation, or focus restoration.
- Visual package owns network, router, auth, or remote state.
- User data or unfinished work is lost on recoverable failure.

## Major

- Existing pattern ignored in favor of duplicated custom markup.
- Hardcoded design-system color, spacing, radius, shadow, or motion.
- Loading, empty, error, disabled, pending, mobile, dark, or high-contrast state omitted.
- Unexpected content insertion or scroll movement.

## Minor

- Inconsistent copy, alignment, density, or token choice that does not block the task.
