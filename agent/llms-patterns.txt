# Commonspace UI patterns

- [Collection states](./patterns/pattern.collection-states.md): Provides complete loading, empty, populated, pagination, and error states for a collection.
- [Conversation list](./patterns/pattern.conversation-list.md): Renders conversations with stable selection, unread semantics, and responsive detail navigation.
- [Feedback and recovery](./patterns/pattern.feedback-recovery.md): Chooses inline, global, or route-level feedback while preserving successful data and unfinished work.
- [Form actions](./patterns/pattern.form-actions.md): Orders validation, pending behavior, primary action, and cancellation for a form.
- [Profile surface](./patterns/pattern.profile-surface.md): Combines profile identity, relationship action, tabs, and state-complete collections.
- [Social feed](./patterns/pattern.social-feed.md): Composes a readable, state-complete social timeline without moving content unexpectedly.

## Templates

- **Strict FSD social shell** (`template.fsd-social-shell`): A React and Vite application shell that keeps Commonspace presentation packages below FSD application slices.
- **Moderation workspace** (`template.moderation-workspace`): A three-region moderation decision workspace with queue, evidence, and controlled actions.
- **Profile settings** (`template.profile-settings`): A profile settings form with validation, pending state, and preserved failure feedback.
- **Social feed page** (`template.social-feed-page`): A state-complete social feed page using presentation models and externally owned remote state.
- **Vite app shell** (`template.vite-app-shell`): A minimal React and Vite shell with Commonspace theme and feedback providers.
